### Features
- Search and download music from YouTube, SoundCloud, Spotify (your own playlists and liked songs) and more
- Multithreaded downloads
- Download cache, so a URL that has already been downloaded is never downloaded twice
- Precedence order, so when the same song is in several folders, the one highest in your order is kept
- Dead or broken links are remembered and not retried
- Duplicate detection with advanced audio fingerprinting, with multiple detection levels
- Search your library with filters, such as song length, with a search cache that updates automatically
- Queue, history, favourites and song ratings
- Album art support, including folder album art, visual effects (CPU and GPU) and mass shuffling
- Metadata editing, with optional mass/bulk editing across multiple tables
- Bit-perfect playback and decoder support
- Playback speed control and automatic gain control
- Automatic updates for yt-dlp and Deno, and ffmpeg is downloaded and managed for you if it is not installed
- Lightweight and portable design with minimal system resources, or use a global config shared across installations
- Built-in wiki, available from inside the app (Top right of the screen)
- Cross-platform compatibility (Windows/Linux)

### Project Origin
RhythmiRust began as two Bash scripts for downloading and searching music. As the project grew, it evolved into a single application with a GUI, minimal dependencies, portability and a focus on memory footprint, performance, and user experience.
